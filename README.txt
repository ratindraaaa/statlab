STATLAB UI prototype v0.1

This is the first interface-only build. Statistical calculations are not connected yet.

Files:
- app.py: Streamlit application
- requirements.txt: Python dependencies

Run locally:
1. Install Python 3.11 or newer.
2. Open a terminal in this folder.
3. Run: pip install -r requirements.txt
4. Run: streamlit run app.py

Next milestone: connect data upload and the first validated statistical test.
